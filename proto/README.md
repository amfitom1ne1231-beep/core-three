# Прототип hero-шейдера

Это **только фон первого экрана** — тот самый «шёлк» с тремя ядрами. Остальное
(прелоадер, pinned-секции, атлас, магнитный курсор) делается в волне 1, уже
внутри Next.js. Здесь голый WebGL1 без зависимостей, чтобы крутить материал
и палитру, ничего не пересобирая.

## Запуск

```bash
cd /Users/island001/CoreThree/proto && python3 -m http.server 4321
```

Дальше открыть http://localhost:4321 (нужен именно сервер, не файл: шейдеры
подключаются как ES-модуль).

## Что смотреть

1. **Водить курсором.** За ним остаётся след: скорость впрыскивается в поле
   потока, завихряется и оседает секунду-две. Складки шёлка сносит этим потоком.
2. **Прокрутить страницу.** Искажение сдвигается, к низу кадр уходит в чистый
   чёрный — это стык с первой секцией контента.
3. **Читаемость.** Крупный заголовок и мелкий моно-текст лежат поверх шейдера
   специально: видно, не съедает ли их блик на складке.
4. **Клавиша T** — переключение на «молочный шёлк». Это направление светлой
   темы из волны 2: та же геометрия складок, другая палитра и свет.
5. **Мобильный.** Открыть с телефона или сузить окно до 375px: шейдер
   автоматически уходит на 70% разрешения и отключает флюид-проход, октавы шума
   остаются — иначе материал выглядит резиной, а не шёлком.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `H` | показать/скрыть панель |
| `T` | тёмная ↔ молочная тема |
| `R` | сброс к значениям по умолчанию |

## Как передать мне выбранные настройки

Накрутить ползунки → **Скопировать JSON** → вставить в чат. Эти числа станут
дефолтами компонента в волне 1.

## Группы ползунков

- **Геометрия полотна** — масштаб и сила складок, скорость, октавы шума.
  Октавы — главный рычаг производительности: 3 достаточно, 4–5 дают детализацию
  ценой кадров.
- **Три ядра** — вес каждого из трёх источников света. Ядра дышат с разной
  фазой, поэтому поверхность не выглядит зацикленной. Выкрутить второе и третье
  в ноль — станет видно, насколько метафора читается.
- **Свет и материал** — экспозиция, мягкий блеск, искра на гребнях, свечение
  по краю, тонкая плёнка (радужность), линии сгиба, виньетка, дизеринг.
  Дизеринг в ноль — на тёмных градиентах появятся полосы, это и есть причина,
  по которой он нужен.
- **След курсора** — насколько поток несёт складки, как быстро оседает,
  сила завихрения.

## Пресеты

- **Шёлк** — стартовая точка
- **Глубокий** — темнее, крупнее складки, меньше блеска
- **Ясный** — светлее и контрастнее, больше искры
- **Ртуть** — металлический, жёсткие блики
- **Спокойный** — медленный, для страниц, где фон не должен спорить с текстом

## Отладка из консоли

```js
__ct.fieldStats()   // живёт ли след курсора: ink, скорость, число ячеек
__ct.P              // текущие параметры
__ct.mode = 1       // молочная тема
```
